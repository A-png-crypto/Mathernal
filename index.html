ABOUT THE PROJECT

Research prototype

This web application demonstrates maternal health risk classification using an Artificial Neural Network. The model was trained separately for each dataset and the browser performs the final prediction using the saved ANN parameters.

This is an educational/research prototype and is not a substitute for professional medical diagnosis.

Datasets

  • Polyclinic Dataset — 500 records
  • UCI Maternal Health Risk Dataset — 1,014 records
  • Mendeley Dataset — 6,103 records

Patient identifiers from the Mendeley source are excluded from the public copy because they are not model features.
